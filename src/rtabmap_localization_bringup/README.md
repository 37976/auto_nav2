# rtabmap_localization_bringup

This package groups RTAB-Map localization pipelines and XFeat-native odometry helpers in one place:

- pure RTAB-Map
- SuperPoint + RTAB-Map
- XFeat + RTAB-Map
- XFeat native RGB-D odometry

Launch files:

- `gazebo_nav_rtabmap_localization.launch.py`
- `gazebo_nav_superpoint_rtabmap_localization.launch.py`
- `gazebo_nav_xfeat_rtabmap_localization.launch.py`
- `gazebo_nav_xfeat_odometry.launch.py`
